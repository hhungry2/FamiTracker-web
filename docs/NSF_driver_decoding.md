# NSFのドライバ別解読

2026-10-10: ロックマン1・2の標準ドライバー用に、曲構造の直接解読・NSFPlayによる音色解析・自動再構築を組み合わせた読み込みを追加しました。[対応範囲と検証（日本語）](NSF_game_drivers.ja.md) / [English](NSF_game_drivers.en.md)。以下の詳細はDn-FT専用デコーダーの説明です。

実装日: 2026-10-06 / [Issue #14](https://github.com/hhungry2/FamiTracker-web/issues/14)

読み込みから再構築までの利用ガイド: [日本語](NSF_import_and_reconstruction.ja.md) / [English](NSF_import_and_reconstruction.en.md)。

NSF読み込み画面の「読み取り方式」で「ドライバ別解読（Dn-FT / ロックマン1・2）」を選ぶと、対応するNSF内部の楽曲データを解読します。「演奏解析（現在の方式）」も引き続き選べます。曲の初期選択は全曲、上限は先頭64トラックです。結果は1つのモジュールとして開き、通常の保存で `.dnm` に保存します。

## 対応範囲

- このリポジトリのDn-FamiTrackerが書き出す **Dn-FT 2.16** ドライバ。これはドライバの識別バージョンで、アプリのバージョン番号とは別です。
- NSF、NSFe、NSF2。基本音源2A03とVRC6、VRC7、FDS、MMC5、N163、S5B、および複数音源の構成。
- 通常配置、圧縮配置、パターンとDPCMのバンク切り替え。
- パターン行数、演奏順、ノート・空行・音切り・リリース・エコー、圧縮されたノート間隔、初期速度・テンポと途中の変更、グルーヴ、Bxx／Dxx／Cxx。
- インストゥルメントのシーケンス、FDSの波形と変調、N163の波形、VRC7のパッチ、DPCMサンプルと割り当て、対応するエフェクト。
- PAL、標準・独自のフレームレート、ビブラート方式、リニアピッチ、書き出された音程テーブル。チューニングの元の操作値は残らないため、同じ音程になるテーブル差分に置き換えます。

直接解読では、演奏解析の「長さ」「パターンの行数」「ループ検出」「先頭の無音を除く」を使いません。書き出された行数と命令を使うためです。直接解読できないファイルは演奏解析へ切り替わり、切り替えたことを表示します。

## 復元できない情報と切り替え条件

音色名・サンプル名、未使用データ、統合前のパターン番号、行強調はNSFに残らず、元の編集状態の完全復元はできません。ノイズの元のオクターブとDPCMの元のキー・音色分けも失われるため、同じ音で演奏できる割り当てに置き換えます。シーケンスやグルーヴの番号は再割り当てします。

ドライバの識別名だけでは判断せず、再配置を考慮してドライバ本体を照合します。未知の版、改造されたコード、未対応のメタデータや実行形式、範囲外の参照、不整合な圧縮データ、復元後の音程テーブルが一致しない場合には演奏解析を使います。展開したパターンデータには32 MBの上限があります。

**全てのDn-FamiTracker製NSFを直接解読できる段階ではありません。** 付属デモでは「The Wavetable That Doesn't Wanna Be」を直接解読し、元のパターン行数と再生音を確認しました。他の4曲の書き出しには、後方のパターンに行数と整合しないストリームがあり、現在は演奏解析へ切り替えます。次のパターンのデータを音符として読み続けないための検査です。これらの圧縮形式の追加調査はIssue #14に残しています。

## 検証

`web/test/nsf-driver.mjs` は元のモジュール→NSF／NSFe／NSF2→直接解読→保存・再読込を検証します。各音源と複数音源の検証用モジュールで、32行・3フレームの演奏順、速度変更、シーケンス、波形、DPCMを復元し、各トラックのPCMを元のモジュールと比較します。PAL・73 Hz・グルーヴ・旧ビブラート・リニアピッチ・DPCMバンク・調律テーブル・外部OPLL、1曲選択、64トラック、破損参照、キャンセルも検証します。画面から呼び出すワーカー処理では、方式の選択、全曲と1曲の演奏解析への切り替え、キャンセル後の編集中データの保持を確認します。

2A03のチャンネル別比較では、NSFPlayの直接再生に対する短時間スペクトルの類似度は次の通りでした。WAV出力の前置き無音を合わせています。これは全ファイルの波形の完全一致を保証するものではありません。

| チャンネル | ドライバ別解読 | 演奏解析 |
| --- | ---: | ---: |
| Pulse 1 | 0.959 | 0.959 |
| Pulse 2 | 0.959 | 0.959 |
| Triangle | 0.984 | 0.984 |
| Noise | 0.786 | 0.786 |
| DPCM | 0.973 | 0.973 |

## 実装箇所

- `web/html/dnft-nsf-driver-import.mjs`: ドライバ照合、参照・バンク・パターン圧縮・音色の解読、別エンジンでのモジュール作成。
- `web/tools/nsf_driver_profiles.mjs`: NSF書き出しと同じ生成済みドライバから照合プロファイルを作成。ビルド時に生成し、未知の版を自動で受け入れない。
- `web/html/dnft-session-engine.mjs`: 読み取り方式を選択し、未対応時は演奏解析へ切り替える。失敗・キャンセル時は編集中のモジュールを保持。
- `web/html/dnft-files.mjs`: 読み取り方式の選択、対応状態と結果の表示。
